# TauriTavern Personal · Android

Приложение для общения с ИИ через карточки персонажей на Android. **obiyeuy** развивает удобство чата, настройку API, сохранение локальных данных и совместимость расширений.

## Назначение

Персональная версия предназначена для **Android 8.0+ и ARM64**. Чаты и настройки хранятся локально; ответы модели поступают от настроенного пользователем API.

Используются форматы SillyTavern для карточек, чатов, книг мира и пресетов. Работа сосредоточена на мобильной навигации, вводе параметров API, проверке соединения, подтверждении сохранения, повторных попытках и совместимости расширений, скриптов карточек и медиа. Совместимость определяется реализованным и проверенным поведением.

## Установка и обновление на телефоне

Имя пакета — `com.tauritavern.personal`. APK публикуются в [Releases этого репозитория](https://github.com/obiyeuy/TauriTavern/releases); имя файла оканчивается на `android-arm64-v8a.apk`.

**Репозиторий уже публичный; первый публичный APK Release и онлайн-обновления ещё готовятся.** Успешная локальная сборка или установка на телефон не означает, что Release опубликован.

После запуска публикаций установите первый APK из этого репозитория. Затем проверяйте обновления в разделе версии/информации приложения, открывайте Release, скачивайте APK и подтверждайте обновление в установщике Android. USB не нужен. Обновление с тем же пакетом и подписью сохраняет существующие данные приложения.

Stable выпускается из `main` с фиксированной версией. Canary собирается из `dev` и обновляет тег `Canary` после проверки. Подробности — в [руководстве по публикации](docs/PersonalDevelopment.md).

## Начало работы

Создайте или импортируйте персонажа. Выберите поставщика API или протокол, заполните отдельные поля базового URL, ключа API и ID модели. Сохраните настройки и проверьте соединение. Пример базового URL: `https://api.example.com/v1`; модель и протокол должны соответствовать документации сервиса.

При ошибке 404 проверьте итоговый URL запроса, протокол, модель и ответ сервера. В отчёте укажите версии приложения и ОС, модель телефона и шаги воспроизведения. Скрывайте ключи в снимках экрана и журналах.

## Разработка

Нужны **Node.js 24, pnpm 11, Rust stable, JDK 21, Android SDK 36 и NDK r29**. Публикация персональной версии также требует исходной конфигурации подписи.

```sh
git clone https://github.com/obiyeuy/TauriTavern.git
cd TauriTavern
pnpm install --frozen-lockfile
pnpm run check
pnpm run android:build:personal
```

Работайте в отдельной ветке задачи; после обзора и проверок Android изменения включаются в `dev`. Stable использует проверенный `main`. Документы: [разработка](docs/PersonalDevelopment.md), [Android](docs/AndroidDevelopment.md), [фронтенд](docs/FrontendGuide.md), [контракт с хостом](docs/FrontendHostContract.md) и [архитектура](docs/BackendStructure.md).
