# TauriTavern Personal 2.4.1

此版本整理了移动界面、配置保存、聊天资源与连接错误处理，并为个人发行建立独立的 GitHub 更新来源。

- API 设置按连接来源、地址、密钥、模型和测试组织；长地址可换行编辑，保存等待原生配置确认。
- 聊天、附件与世界书使用已确认的写入结果发布状态；写入、读取与删除失败保留实际错误。
- 手机导航、原生设置投影、输入法与异步连接操作沿同一状态来源更新。
- 设置重复刷新减少无效 DOM 更新。同条件本地 Chrome 测量中，含微任务的中位耗时从 8.3 ms 降至 1.2 ms；该结果只描述设置刷新，不代表真机冷启动速度。
- 个人构建查询自身的 GitHub Releases。更新检查失败保留请求地址和 HTTP 状态；404 会说明公开访问及渠道发布条件。
- 默认更新来源、关于页、欢迎页、反馈入口与开发文档统一指向 `obiyeuy/TauriTavern` 个人 fork，上游贡献署名保留在来源说明中。

Android 包名保持 `com.tauritavern.personal`，签名沿用原个人证书。请覆盖安装；应用不会在更新过程中清除聊天、API 配置或角色卡。

该版本的源码与自动测试可在提交和 Actions 中追溯。真机上的特定第三方 API、角色卡与 MVU 行为仍需结合实际响应核对。
