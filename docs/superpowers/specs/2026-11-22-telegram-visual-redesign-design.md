# TauriTavern Telegram 视觉重设计

## 目标

让手机端日常聊天看起来像一个完整的聊天应用，而不是给原酒馆页面套一层颜色。聊天、角色、历史和更多页面共享 Telegram 经典浅色与 Night 两套语义主题、间距、头像、分组和反馈层级。用户已反复明确要求直接借鉴 Telegram 并实现，沿用既有任务分支与目录，不再重新要求设计审批。

## 视觉方向

- 默认蓝色顶栏、白色面板、淡色纹理背景、白色入站与浅绿色出站气泡；抽屉的主题按钮切换到 Night，偏好仅保存于本机。
- 采用蓝色主操作色、绿色在线状态和低对比分隔线；正文保持高对比，辅助信息降低亮度但不消失。
- 顶栏、抽屉菜单、角色行、历史行和设置行使用统一的 8px 间距节奏、48px 触控目标和 12–16px 圆角。
- 消息保持 Telegram 的左右气泡语义：角色消息靠左、用户消息靠右；操作按钮只在交互时出现。
- shell 使用统一 24px、2px 描边 SVG；原生面板保留现有 Font Awesome 的语义，不增加网络字体依赖。

## 交互结构

- 聊天页保留单一主路径：会话顶栏、滚动消息区、底部 Composer。
- 顶栏菜单打开左侧抽屉。抽屉包含账户区、聊天/角色/历史/设置菜单、当前会话预览、夜间主题入口；角色页保留真正的角色搜索。
- 角色、历史和更多通过同一顶栏返回；更多内容按“连接、生成、内容、外观、应用”分组。
- 角色和历史仍由现有原生面板负责数据和操作；新卡、世界书、聊天记录继续沿原有数据源渲染。

## 约束

- 不复制或改写角色卡、世界书、聊天、API 凭据和正式备份。
- 继续遵守安全区、Android 48dp 触控目标、横屏、小屏、大字号和 reduced-motion 支持。
- 低端手机避免模糊和大面积图片；抽屉使用实色面板，聊天背景只用轻量 CSS 图案。

## 参考与实现选择

- Telegram 官方截图：<https://telegram.org/tour/screenshots>。借鉴会话顶栏、列表行、气泡、圆形头像和蓝色主操作层级，继续使用 TauriTavern 的身份。
- 全面重写同一份 mobile shell CSS，替代原有三段互相覆盖的样式；不继续追加主题补丁。
- 保留原有面板和消息操作 DOM 契约；编辑、复制、分支等操作通过消息焦点/点击显现，不永久隐藏。
- 电脑宽屏使用常驻左栏与中间聊天；手机维持全宽聊天与可关闭抽屉。预览使用单独的演示数据，绝不读取用户生产数据。

## 细节打磨

用户已认可整体，继续沿当前 Telegram 经典浅色/Night 方向优化细节。

- 统一 4/8px 间距、16px 正文与更紧凑的行距；减淡缩小壁纸纹样，调整气泡、时间和头像的对齐。
- 手机输入提示改为短文案，仍由原有连接状态写入者更新；不写草稿、不另加观察器。
- 角色页将搜索、导入、排序收在一行，常用筛选用简短标签；保留真实筛选状态，活跃的群组/文件夹筛选仍可清除。
- 设置采用浅底卡片、分组行、统一图标底色；原生设置内容、历史操作与数据源继续保留。
- 收敛旧控件的 opacity/filter 和 hover 表现，避免可点控件看起来被禁用；保留真实 disabled 和键盘焦点。
- 校验短消息操作面板的视觉层叠与实际点击，覆盖夜间、横屏、放大字号和输入视口。
- 原生欢迎页和抽屉快捷入口先进入相同的手机导航流程，再执行原生布局，使页面标题、返回和聊天焦点保持一致。
